# Каталог взуття

Десктопний застосунок на Windows Forms (.NET Framework) для ведення бази даних каталогу взуття в Microsoft Access (`Каталог взуття.accdb`).

## Що вміє

З головного вікна відкриваються форми для перегляду й редагування таблиць бази:

- Бренди;
- Країни;
- Матеріали верху;
- Матеріали підошви;
- Цільова аудиторія;
- Каталог взуття (основна таблиця).

Кожна форма показує дані в таблиці з навігатором і дозволяє додавати, змінювати й зберігати записи (через `DataSet` і `TableAdapter`).

## Запуск

1. Потрібен Microsoft Access Database Engine (провайдер OLE DB для `.accdb`).
2. Відкрийте `WindowsFormsApp1.sln` у Visual Studio і натисніть F5.
